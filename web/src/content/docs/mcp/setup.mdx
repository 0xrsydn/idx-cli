Paste this into your coding agent. It follows
[agents/install.md](/agents/install/): installs idx, registers idx-mcp with

```text wrap
Install idx-cli and its MCP server for me by following https://idx.rasyidanaf.com/agents/install.md, then show me that it works.
```

Or set it up yourself:

## 1. Get the server

Nothing to install if your client can run `npx`: the configs below use
`npx -y idx-mcp`. Otherwise install the binary once and use `idx-mcp` as the
command:

```bash
cargo install idx-mcp                                  # Rust 1.89+
nix profile install github:0xrsydn/idx-cli#idx-mcp
```

## 2. Add it to your client

<Tabs syncKey="agent">
<TabItem label="Claude Code">

```bash
claude mcp add idx -- npx -y idx-mcp
```

</TabItem>
<TabItem label="Codex">

`~/.codex/config.toml`:

```toml
[mcp_servers.idx]
command = "npx"
args = ["-y", "idx-mcp"]
```

</TabItem>
<TabItem label="Cursor">

`~/.cursor/mcp.json` (or `.cursor/mcp.json` in a project):

```json
{
  "mcpServers": {
    "idx": { "command": "npx", "args": ["-y", "idx-mcp"] }
  }
}
```

</TabItem>
<TabItem label="opencode">

`opencode.json` in a project, or `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "idx": { "type": "local", "command": ["npx", "-y", "idx-mcp"], "enabled": true }
  }
}
```

</TabItem>
<TabItem label="pi">

`~/.pi/agent/mcp.json`:

```json
{
  "mcpServers": {
    "idx": { "command": "npx", "args": ["-y", "idx-mcp"], "exposure": "direct" }
  }
}
```

`"exposure": "direct"` gives the agent each tool by name.

</TabItem>
<TabItem label="Hermes">

`~/.hermes/config.yaml`:

```yaml
mcp_servers:
  idx:
    command: npx
    args: ["-y", "idx-mcp"]
    enabled: true
```

</TabItem>
<TabItem label="Other">

Any MCP client that runs stdio servers: command `npx`, arguments
`-y idx-mcp` (or the command `idx-mcp` if installed). Add `--allow-sync` to
the arguments to expose `ownership_sync`.

</TabItem>
</Tabs>

These are the setups that `tests/agents/agent-smoke.sh` drives with real
agents.

## 3. Get ownership data

Ownership tools read a local database. Fill it once:

```bash
npx -y idx-cli ownership sync    # or: idx ownership sync
```

Or start the server with `--allow-sync` so the agent can call
`ownership_sync` itself.

## 4. Check it works

Ask your agent:

> What is BBCA's free float, and who is its largest holder?

It should call `get_shareholders` and answer with the free float and
DWIMURIA INVESTAMA ANDALAN, the largest holder.

See [all tools](/mcp/tools/).
