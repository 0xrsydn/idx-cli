# idx-mcp

MCP server (stdio) for Indonesian stock market (IDX) data: quotes, price
history, screener, company financials, analysis, and KSEI shareholder
ownership. This package downloads the native `idx-mcp` binary for your
platform from the matching GitHub release and verifies its SHA-256.

```bash
claude mcp add idx -- npx -y idx-mcp
```

See https://github.com/0xrsydn/idx-cli#mcp-server for the tools and options.
